# TrackHub 🚀

Веб-застосунок для відстеження завдань та управління проєктами в рамках DevOps лабораторних робіт.

---

## ☸️ Розгортання в Kubernetes (Lab #3 / DVO-L3-7F2A91)

### ⚙️ Параметри конфігурації

#### 1. ConfigMap (`trackhub-config`)
| Змінна | Значення за замовчуванням | Опис |
| :--- | :--- | :--- |
| `APP_ENV` | `production` | Режим роботи застосунку |
| `DEFAULT_PRIORITY` | `medium` | Пріоритет завдань за замовчуванням |

#### 2. Secret (`trackhub-secret`)
| Ключ | Приклад значення | Опис |
| :--- | :--- | :--- |
| `DATABASE_URL` | `sqlite:///./test.db` | Рядок підключення до бази даних SQLite |
| `API_SECRET_KEY` | `super-secret-key-123` | Секретний ключ для підпису та аутентифікації |
